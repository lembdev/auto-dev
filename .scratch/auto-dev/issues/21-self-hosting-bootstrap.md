# Самохостинг: auto-dev разрабатывает сам себя

Type: grilling
Status: resolved
Blocked by: 13

## Question

Можно ли вести репо auto-dev через Установку auto-dev, с какого момента, какие ограничения и порядок bootstrap.

## Answer

Решено 2026-11-05 (рекомендации агента, принятые пользователем заранее).

1. **До первого релиза** (v0.1.0: Оркестратор + ask_human + merge + минимальный UI) код пишется руками в Claude Code локально; задачи всё равно ведутся в GitHub Issues по тому же контракту, чтобы потом не переделывать.
2. **После v0.1.0:** отдельная Установка «auto-dev для auto-dev» на своей VM, Продукт = `lembdev/auto-dev`. Одна VM = один Продукт (карта), значит Breedly и auto-dev живут на разных VM.
3. **Ограничения:** Установка обновляет себя только релизами (13), никогда с `main`; релиз режет человек после ручной проверки на своей машине. Агенты в этой Установке не имеют доступа к `/etc/auto-dev` и к Рантайм-индексу хоста (обычные права пользователя `auto-dev` уже это обеспечивают, так как агенты работают в worktree клона).

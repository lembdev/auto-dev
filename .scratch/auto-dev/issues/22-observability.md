# Наблюдаемость: логи, метрики лимита, статистика задач

Type: grilling
Status: resolved
Blocked by: 08, 12

## Question

Где и как пишутся логи Оркестратора, что логируется из работы Агентов, как хранится история расхода лимита, какая статистика по Задачам показывается.

## Answer

Решено 2026-11-05 (рекомендации агента, принятые пользователем заранее).

1. **Логи Оркестратора:** структурированный JSON в stdout (pino), journald через systemd; уровень в `/etc/auto-dev/env` (`AUTO_DEV_LOG_LEVEL`, default info). Логируются переходы Стадий, вызовы GitHub API (метод, путь, статус, без тел), старты/остановки процессов, ошибки. Текст Агентов и tool-вызовы не логируются: они в транскрипте `sessionStore`.
2. **Лимит:** раз в 10 мин снимок `five_hour` / `seven_day` в таблицу `limit_samples` (хранить 30 дней). График на странице «Статистика».
3. **Статистика Задач** считается из `transitions`: за 7 / 30 дней: взято, влито, тупиков; среднее время Стадий; среднее число Кругов. Без внешних систем (Prometheus, Grafana) и без экспорта.
4. **Просмотр логов в UI:** последние 500 строк journald на странице «Статистика» через `journalctl -u auto-dev` (sudo NOPASSWD на эту команду, как с `update`).

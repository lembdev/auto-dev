# Жизненный цикл worktree, веток и процессов

Type: grilling
Status: resolved
Blocked by: 11

## Question

Когда удаляются worktree и ветка Задачи: сразу после merge, после закрытия issue, по таймеру. Что чистится при Отмене (issue закрыта руками), при тупике (`ready-for-human`) и при повторном `ready-for-agent` после тупика (старый PR закрыт, новая Сессия: новая ветка или та же). Что делать с зависшими процессами `claude` вне индекса. Поведение при переполнении диска: порог, что чистится первым, останавливать ли взятие новых Задач. Сохраняется ли что-то для разбора (лог Стадии, ссылка на Сессию) после удаления worktree.

## Notes

- Из 08: раскладка `/var/lib/auto-dev/repo/.claude/worktrees/<имя>`, намерения в индексе, сироты по PID гасятся на старте.
- Из 06: тупик = `ready-for-human`, возврат = `ready-for-agent` со старта с чистой Сессии и нового worktree, старый PR закрывается; Отмена = issue закрыта без влитого PR.
- Ждёт 11: метод слияния и что остаётся от ветки после merge.
- Решение по 11 (2026-11-05): после squash-merge ветка на GitHub удаляется Оркестратором, Сессия Реализатора закрыта; здесь решить только локальное: worktree, локальная ветка, сроки.

## Answer

Решено 2026-11-05 (рекомендации агента, принятые пользователем заранее).

1. **Имена:** worktree `issue-<N>` (повторная попытка `issue-<N>-r<k>`), ветка `worktree-issue-<N>[-r<k>]`, путь `/var/lib/auto-dev/repo/.claude/worktrees/<имя>`.
2. **Завершение (PR влит):** сразу после итогового комментария удаляются worktree и локальная ветка; remote-ветку удалил Оркестратор (11). Остаются: PR, транскрипт в `sessionStore`, `transitions` в индексе.
3. **Отмена:** процесс гасится, PR закрывается, remote-ветка, worktree и локальная ветка удаляются.
4. **Тупик (`ready-for-human`):** ничего не удаляется: worktree, ветка и PR с `WIP:` остаются для разбора. Повторный `ready-for-agent`: старый PR закрывается, старый worktree и ветки удаляются, новая попытка с суффиксом `-r<k>` и чистой Сессией.
5. **Чужие процессы:** на старте и раз в час `pgrep -u auto-dev claude` минус PID из индекса -> SIGTERM, через 10 с SIGKILL.
6. **Диск:** при заполнении `/var/lib` >= 90 % Пауза взятия + баннер в UI; автоматически ничего не удаляется. Освобождение: человек снимает тупиковые Задачи (Отмена или повторный запуск) или чистит руками.

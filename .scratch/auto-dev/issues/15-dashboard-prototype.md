# Прототип экрана режима разработки (дашборд агентов)

Type: prototype
Status: resolved
Blocked by: 09, 14

## Question

Как выглядит экран режима разработки: список задач в работе со стадиями, карточка агента со статусом (работает / ждёт человека / завершён), вход в интерактивный диалог, индикатор лимита подписки. Сделать кликабельный прототип через /prototype и отреагировать на него.

## Notes
- Из research 05 (Codeman): идеи для прототипа: tile grid живых Агентов, окна сабагентов с линиями к родительской Сессии, «away digest» (что случилось с последнего визита: Запросы к человеку, завершённые Задачи).

## Answer

Решено 2026-11-05. Прототип: `.scratch/auto-dev/research/15-dashboard/index.html` (один файл, mock-данные, открыть в браузере; `?variant=A|B|C` и плавающая панель внизу слева переключают три раскладки, стрелки клавиатуры тоже; `&open=138` сразу открывает панель Агента в Ожидании).

1. **Шапка общая для всех вариантов:** Продукт, переключатель Режим разработки / Режим планирования (планирование - заглушка), два индикатора лимита (`five_hour`, `seven_day`: процент, время сброса, подсветка 60 / 85 %), Слоты «занято / max», тумблер «Пауза» с баннером-пояснением, кнопка «Обновить» с баннером о новой версии.
2. **Три раскладки тела:** A - одна колонка (digest, В работе, Готовые, Тупики) и панель Агента выдвижной шторкой справа; B - плитки живых Агентов с превью последних событий и открытым Запросом прямо на плитке, digest / Готовые / Тупики в боковой колонке, панель Агента на весь экран; C - колонки по Стадиям (Готовые | Реализация | QA | Merge | Тупики), digest сворачиваемой полосой, панель Агента нижней половиной экрана.
3. **Карточка Задачи везде одна:** номер и заголовок issue, milestone, Стадия (QA с Кругом «2 из 3»), бейдж состояния Агента (работает / idle / ждёт человека / остановлен), PR, время с начала. Карточка в Ожидании жёлтая.
4. **Панель Агента (09):** лента событий: текст ассистента, вызовы tool одной строкой с раскрытием input / result, серые системные строки (resume, compaction, остановка), thinking свёрнут, сабагент вложенным блоком. В Ожидании наверху ленты блок Запроса: вопрос, варианты кнопками (подставляют текст в поле, не отправляют), поле свободного текста, «Ответить». После Ответа блок исчезает, Агент переходит в «работает», Слот занят.
5. **Диалог:** поле ввода внизу всегда; отправленное уходит в очередь «ещё не доставлено» с крестиком удаления и доставляется после «конца Хода» (mock по таймеру); в Ожидании очередь ждёт Ответа; сообщение остановленному Агенту начинает новый Ход.
6. **Кнопки:** «Остановить ход» (активна только у работающего; Сессия жива, Слот свободен) и «Отменить задачу» с подтверждением внутри панели (issue закрывается без PR, Задача исчезает из списка).
7. **«С прошлого визита»:** три строки: Запросы к человеку (ссылки открывают панель), завершённые Задачи, Тупики. Готовые Задачи и Тупики (`ready-for-human`, с причиной) - отдельные секции, не кликабельны.
8. **Сознательно нет:** реального таймера «время с начала», живого стрима, транспорта WS, «у стены» (12.4) и пре-арма, уведомлений, окон сабагентов с линиями к родителю (отвергнуто в 09 в пользу вложенных блоков), содержимого Режима планирования (тикет 10), истории завершённых Задач, мобильной раскладки для C.

### Выбор раскладки (2026-11-05)

Выбрана **раскладка A** (одна колонка: digest, В работе, Готовые, Тупики; панель Агента шторкой справа) как самая простая и пригодная для телефона. Из B берётся одно: на карточке Задачи в Ожидании показывается текст открытого Запроса (первая строка) и кнопка «Ответить», открывающая панель. Раскладки B и C в спеку не идут.
